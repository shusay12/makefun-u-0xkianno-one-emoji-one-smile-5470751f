An entry for the make.fun bounty [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

Running `main.py` (Python 3.13, standard library only, no network) writes
exactly one emoji — 🤗 Hugging Face (U+1F917) — to `/output/entry.txt`:
the single emoji most likely to make a stranger smile. A hug is the most
direct act of warmth one stranger can offer another: instantly kind and
welcoming, understood the same way at any age or background, a deliberate
pick rather than the default smiley, and a warm greeting rather than
intimacy or flirtation. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
